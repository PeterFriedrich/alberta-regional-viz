## 3. Technical Learnings
- **Run the full `pytest` before pushing any `docs/DECISIONS.md` change.** `BRIEF.md` is generated from it, and `test_committed_brief_is_current` fails otherwise.
  - #38's first push went red for exactly this. Branch protection blocked the merge, as designed.
  - Run `.venv/bin/python scripts/make_brief.py --write`. Without `--write` it only prints.
- **How to dry-run a copier update:**
  - `git clone -q <repo> <scratch>/tu && cd <scratch>/tu && git switch -c tu && ~/.local/bin/copier update --trust --defaults --vcs-ref <sha> --conflict inline`;
  - symlink `.venv` from the main clone to run the tests.
- **Conflict markers in prose:** `grep -rln '<<<<<<<'` hits files that *mention* markers (`check_fit_table.py`, `COPIER.md`, the S4 archive). Check with `grep -n '^<<<<<<< '` instead.
