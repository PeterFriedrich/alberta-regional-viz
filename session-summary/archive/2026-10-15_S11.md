## 3. Technical Learnings
- **Edmonton's FCSS cutoff is "before 2007"**: rows start in 2007 (`NOT_COMPARABLE[("fcss","edmonton")] = 2007`). S10's handoff said "through 2007"; the code and DECISIONS say "before 2007".
- **Which data is committed:** `equalized_long.csv` and `member_assessment.csv` are gitignored. The other five processed CSVs are committed. The map marks the gitignored ones amber, as "built locally".
- **matplotlib edge anchoring:** run `fig.canvas.draw()` first. Then each box is `text.get_bbox_patch().get_window_extent(renderer)`, inverted through `ax.transData`. Fixed `shrinkA/B` in points does not fit variable-width boxes.
- **Artifact Mermaid:** the viewer renders `<pre class="mermaid">` natively with no library. The text inside must be HTML-escaped.
