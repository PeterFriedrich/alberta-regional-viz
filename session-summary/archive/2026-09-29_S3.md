## 3. Technical Learnings
- **External check source:** summary pages exist only in the 1999 (p11) and 2000
  (p10) reports. Other years have only internal checks.
- **Continuity-scan sizing (NR, 462 member-years):**
  - A ring member's deviation from its neighbours' midpoint: median 3%, p95 12%,
    p99 86%.
  - A flat pp threshold with the core included flags Edmonton's normal 5–10% annual
    moves. That's why the core is excluded.
  - The ≥0.25 pp condition is what stops real growth by small members (Chestermere's
    +66%) from firing the newest-year check.
- **Known gap:** anomalies in the core's own values (Calgary linear 2002) are not
  checked.
- **What went wrong this session** (recorded in the findings doc):
  - I first used the wrong neighbour year for the Calgary linear adjustment.
  - I said "8 smallest members" when it was 6.
  - A Python `str.replace` for the ledger #2 note silently didn't match. Use
    `assert old in s` before every replace, which I did afterwards.
- Every pp-effect figure is "replace the value with its neighbours' midpoint and
  recompute the core share".
