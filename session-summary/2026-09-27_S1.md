## 3. Technical Learnings
- **Equalized reports:** open.alberta.ca CKAN `package_show?id=2368-657x` has one
  PDF per report year, 2009–2026. **`taxation_year = report_year − 1`**
  (MA *Guide to Equalized Assessment* §5). The older series is `1844032`, reports
  1998–2008.
  - **Image-only (no text):** reports 2008, 2009 and 2010.
  - **Text layer:** reports 1998–2007 and 2011–2026.
- **The 2012–2016 layouts print zero as a blank cell.** A row can have fewer
  numbers than columns, so values are placed by right-edge x (right-aligned,
  within about 1 pt). A value in the wrong column still sums to its row total,
  so there is a separate alignment check (`ALIGN_TOL = 3`).
- **Layout traps handled in `parse_equalized.py`:**
  - numbers inside names ("No. 31"): only the trailing run of numbers right of
    the Residential header minus 25 pt counts as values
  - bold SUB/GRAND TOTAL rows shifted 3–5 pt (`SUB_TOL = 8`; this is safe
    because subtotals are reconciled column by column)
  - a wrapped value on a 2011 subtotal ("5,671,306,0" + "53"; `FRAG`)
  - names wrapping below the numbers line (`CONT_GAP`, chained) and above it
    (`PRE_GAP`; e.g. 2016 Redwood Meadows)
  - "GRAND TOTAL" printed in the name column
  - the name column's left edge varies by year (84–120 pt), so it is derived
    per page (`_name_x0`)
  - boilerplate lines ("Report Date:", "Prepared:", "Classification:",
    "Page N")
  - a railway column that exists through report 2019 and is absent from 2020
- **The City's figures decoded (by fit, not stated by the City):**
  - UPE01548's 72%→60% ≈ **NR + linear, excluding M&E**
  - the 2016 "76%" ≈ **NR only**
  - This differs from decision 10's headline (NR only), so the pipeline
    publishes all three bases (`nr`, `nr_linear`, `nr_all`).
- **Calgary holds 81–94% of its region's NR** (taxation years 2010–2025), against
  Edmonton's 76%→61% on the NR-only basis. The Calgary decline since 2016 has
  not been investigated.
- **Guard gotcha:** `check_doc_citations.py` flags "`DECISIONS.md`… lines 1912"
  as a line-number citation. Also, `cmd | tail` hides the exit code: that pushed a
  red guard once this session (fixed in `6ef5af5`). Capture `$?` or
  `PIPESTATUS` instead.
- **Full parse takes about 3–4 minutes** on this box, so run it with
  `run_in_background`.
- The research reports' earlier "2017 / ~9,500 ha" Leduc annexation claim is wrong.
  The correct figures are 2019-01-01 and 8,260 ha (MGB 050/18). This is recorded
  in the scope doc.
