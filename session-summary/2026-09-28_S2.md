## 3. Technical Learnings
- **Railway is inside the old NR.** The evidence is I.D. No. 12 Jasper Park:
  - 2005 report: NR 7.2M, railway 5.6M, linear 10.9M.
  - 2004 report: NR 17.4M, linear 10.8M.
  - Beaver County agrees.
- **Railway's size:** railway was 0.03–0.6% of NR in 2007–2019, so where it sits
  moves a core share by ≤0.1 pp.
- **All 1998–2004 reports print M&E *left* of linear.** The order is constant
  within those years, so a test with a swapped header was needed to exercise
  the x-sort.
- **The NR+linear share jumps 67.2% → 71.1% across the 2007–2009 gap** while NR
  only goes 75.3 → 76.2. Market NR more than doubled, while regulated linear
  grew about 25%. It is a composition effect, not a break (TODO caption item).
- **Series values (Edmonton, taxation years 1997 → 2025):**
  - `nr`: 77.2 → 60.9
  - `nr_linear`: 66.4 → 57.5
  - Calgary `nr`: 95.0 → 82.9
- **Debug workflow that worked:** use `parse_pdf` on a single year (fast), and
  register defects in a debug loop by wrapping `pe._check_subtotal` to print
  per-column diffs. Hard-code the defects only after seeing the full list.
- **The full parse takes about 3–4 min.** Run the byte-identity check after
  *every* parser change. It caught the 2011 regression this session.
- `$?` after a pipe reports the pipe's last command; I slipped once
  (`cit=$?` after `| tail`). Redirect to `/dev/null` and check `$?` directly.
