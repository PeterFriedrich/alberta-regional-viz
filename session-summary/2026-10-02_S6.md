## 3. Technical Learnings
- **FIR layouts:**
  - **2009+:** one workbook per year, one sheet per schedule.
  - **1994–2000 and 2004–08:** one `.xlsx` per schedule. The `-E`/`-G` utility
    supplements reuse Schedule D's title, so they are excluded by file name.
  - **2001:** `_colN.XLS` files with **no code row**, mapped by header name in
    `parse_fir.NAME_TO_CODE`. Its folder holds some 2002 files (row YEAR 2002),
    which are not read.
  - **2002 and 2003:** `.xls` in sub-folders. `2003-EA-MR/` is in both zips,
    byte-identical.
  - Three return forms are encrypted.
- Row 2 of every sheet is the header ("YEAR"). The next row holds 5-digit item
  codes, and municipality rows have a 4-digit `CODE`.
- **MR(2) taxable assessment exists only from 2023.** There is **no POPL sheet
  for 2020–2022**.
- **FIR vs PDF, same report year:** 68% exact and 89% within 1%. Where they
  differ, FIR is usually lower (402 vs 82). The cause is unknown and is TODO.
  FIR's 2001 NR column includes railway; other years have railway separately
  (08290).
- **FIR covers report years 2008–2010**, which is the scanned-PDF gap that holds
  Edmonton's 72% anchor year. It is blocked on the gap explanation.
- Ring members' transfers are lumpy. Leduc City's capital transfers went
  8.6M → 45.9M in 2023 (real money), so per-member step tests don't work and
  the test is common-mode.
- `make_brief.py` must be re-run (`--write`) after any TODO, DECISIONS or
  CLAUDE.md edit. Otherwise `test_committed_brief_is_current` fails.
- `tools/todo_archive.py` moves `[x]` items out of TODO.md; run it after closing one.
